# Практична робота №1

## Вибір інструментів розробки та каркас структури клієнтського застосунку

### Тема
Вибір інструментів розробки та каркас структури клієнтського застосунку.

### Мета роботи
Розглянути наявні на ринку інструменти для веброзробки (редактори коду, браузерні DevTools, розширення), обрати й налаштувати робоче середовище для виконання практикумів курсу; створити базовий каркас HTML-структури майбутнього клієнтського застосунку в межах свого варіанта — основу, яку наступні практикуми поступово доповнюватимуть новими шарами (семантика, стилі, адаптивність, JavaScript).

### Варіант завдання
**Варіант 7 — Список бажань (Wishlist)**

- **Назва проєкту:** `wishlist-app`
- **Title сторінки:** «Список бажань»

### Заплановані розділи застосунку
1. Шапка з назвою (header)
2. Форма додавання нового бажання
3. Список бажаних речей (картки з ціною й пріоритетом)
4. Блок підсумкової суми
5. Підвал (footer)

### Використані інструменти розробки
- **Редактор коду:** Visual Studio Code
- **Браузер / DevTools:** Google Chrome DevTools
- **Розширення VS Code:**
  - Live Server
  - Prettier — Code formatter
  - HTML CSS Support
- **Система контролю версій:** Git / GitHub

### Структура проєкту
```
wishlist-app/
├── index.html
├── README.md
├── .gitignore
├── css/
│   └── style.css
├── js/
│   └── app.js
```

### Опис виконаної роботи
1. Проаналізовано та обрано інструменти для веброзробки: редактор коду, браузерні DevTools та корисні розширення.
2. Налаштовано робоче середовище (встановлено VS Code, розширення, перевірено роботу Live Server).
3. Створено базову структуру проєкту `wishlist-app`.
4. Розроблено базовий HTML-каркас сторінки `index.html` з розділами: шапка, форма додавання бажання, список карток бажань, блок підсумкової суми, підвал.
5. Каркас підготовлено для подальшого доповнення семантичною розміткою, стилями (CSS), адаптивністю та логікою (JavaScript) у наступних практичних роботах.

### Висновок
У результаті виконання практичної роботи обрано та налаштовано інструментарій для веброзробки, а також створено базовий HTML-каркас клієнтського застосунку «Список бажань» відповідно до варіанта №7. Створена структура є основою для подальшого нарощування функціоналу в наступних практикумах курсу.
